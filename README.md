# Java Practice 🚀

A collection of Java programs written while learning Java basics — Day by Day.

## 📁 Programs Included

| File | Description |
|------|-------------|
| `Summ.java` | Sum of numbers |
| `Swap.java` | Swapping two variables |
| `TypeCasting.java` | Type casting in Java |
| `UniqueNo.java` | Finding unique numbers |
| `Week.java` | Days of the week |
| `inp.java` | Taking user input |
| `palindrome.java` | Palindrome check |
| `rev.java` | Reversing a number/string |

## 🛠️ How to Run
1. Clone the repo:
   git clone https://github.com/aditi00223/Java_Practice
2. Open any `.java` file in IntelliJ / VS Code / Eclipse
3. Run the `main` method

## 📚 Topics Covered
- Java basics & syntax
- Type casting
- Loops & conditionals
- String/number manipulation
- User input handling
